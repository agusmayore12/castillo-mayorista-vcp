# Castillo Distribuidora VCP — catálogo web

- `index.html`: la web completa.
- `img/`: fotos de los productos. El nombre de cada archivo es el que figura en la columna FOTO de la planilla.

Los productos y precios salen de la planilla de Google Sheets a través del Apps Script (`Codigo.gs`).
Mientras la web no esté conectada al script, funciona en modo demo con la lista de diciembre 2022.
